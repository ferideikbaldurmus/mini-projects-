# startbootstrapcom-templates-and-varied-designs 🎨

A personal collection of responsive front-end projects including:

- Templates cloned from [StartBootstrap.com](https://startbootstrap.com)  
- Various other UI designs and practice projects not sourced from StartBootstrap

**Note:**  
The "Jane" template and the following projects are **not** from StartBootstrap:

- Two-cards  
- Three cards  
- Shadow practical  
- Roadmap  
- Keyframes-practical  
- Css practical  
- Cyrtpto card  
- Animations practical

---

This repository contains multiple folders with projects built using:

- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  

Most projects are based on official StartBootstrap templates, while others are personal or third-party designs used for practice and experimentation.

---

## 💡 Purpose

This repo serves as a personal archive and practice collection for exploring various front-end layout and UI design techniques.

You are welcome to clone or fork this repository for educational or non-commercial use.

---

## 📷 How to Preview

Each project folder includes an `index.html` file that you can open directly in your web browser to view the design locally.
